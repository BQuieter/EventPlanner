# EventPlanner
Десктоп-приложение для управления событиями с календарём, веб-сервер и база данных.
## Основные возможности
1. Регистрация и авторизация пользователей

2. Просмотр событий

3. Создание событий

4. Изменение событий
## Десктоп приложение (WPF)
Десктоп приложение сделано на технологии WPF и по паттерну MVVM
Приложение посылает CRUD запросы серверу и получает ответы
В сервисе по пути `EventPlannerClient/Services/ApiService` нужно убедиться, что `_httpClient.BaseAddress` присвоена ссылка на запущенный сервер
## REST API сервер
Сервер сделан на технологии ASP .NET Core (на основе контроллеров)
Аутентификация происходит с помощью JWT токенов с обновлением
Некоторые действия пользователей логируются в базу данных
## Библиотека классов
В проекте есть общая библиотека классов, которая в основном предназначена для для DTO (Data Transfer Object) классов
## База данных
**СУБД:** Microsoft SQL Server 

**ORM:** Entity Framework Core

**Расположение:** Серверная часть (доступ через REST API)

### Настройка Базы Данных
1. Откройте СУБД для работы с SQL Server

2. Найдите в репозитории файл `CreateDataBase.sql`

3. Выполните этот скрипт

4. При необходимости обновите строку подключения в `EventPlannerServer/appsettings.json`

### Запуск (локально на компьютере)
1. Убедитесь, что база данных успешно создана, и в ней есть первоначальные данные

2. Запустите веб сервер

3. Запустите десктоп приложение
